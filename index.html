Instalação no Android / Criar APK

Opção 1: Instalação Rápida no Android

Instale como aplicativo nativo diretamente no seu dispositivo sem precisar compilar um APK.

Opção 2: Pelo Navegador Chrome (Android)
  1. Abra o menu do Chrome (três pontinhos ⋮ no topo).
  2. Toque em "Adicionar à Tela inicial" ou "Instalar aplicativo".
  3. O ícone do FinControl PRO será criado na sua gaveta de apps!
Opção 3: Gerar Arquivo .APK Físico

Para obter o arquivo `.apk` de instalação clássico:

  1. Hospede este arquivo `index.html` em qualquer site gratuito (como GitHub Pages, Vercel ou Netlify).
  2. Acesse pwabuilder.com ou webintoapp.com.
  3. Cole a URL do seu site para baixar o arquivo **.apk** compilado!
